# RPG 第一版實作紀錄

2026-09-12。範圍是現有 AIF-C01 題庫的新遊玩模式。SQL Quest 的產業／職務分類不納入本站；劇情只串接考題，不改題幹、選項與答案。

## 使用方式

執行 `pnpm dev`，在首頁 AIF-C01 卡片點「RPG 冒險模式」，或進入 `/rpg/aif-c01?view=map`。

- 五地區像素地圖，可預覽尚未開放區域。
- 起源草原有三份委託，每份三題：學習方式、模型生命週期、AWS AI 服務。
- 任務戰鬥、提示、首次作答解析、通關結算與 XP。
- 營火到期回想與下次複習日期。
- 知識圖譜顯示獨立作答與跨日回想證據，與故事完成狀態分開。
- 中英文切換、手機排版、鍵盤操作與減少動態支援。
- 瀏覽器本地存檔，附獨立匯出、匯入與重置；多分頁由 Web Locks 控制唯一寫入者，其他分頁唯讀，持鎖分頁關閉後自動接手。

頁面使用 `view=map|quests|camp|skills|battle`，戰鬥另外帶 `quest`。這是同一個 RPG 路由容器內的深連結，避免將全域 provider 或原有頁面改成遊戲佈局。活動中的戰鬥以存檔中的任務識別為準。

## 資料與隔離

`src/lib/rpg/engine.ts` 是純規則；`useRpgSave.ts` 管理 `aistudyhub:rpg:v1:AIF-C01`。RPG 不呼叫原有成績、錯題與同步寫入 API，不寫 `exam-results`、`wrong-answers` 或 `_syncQueue`。

`QuestionView` 與其子元件直接重用，未修改其既有行為。RPG 介面直接繼承專案 Happy Hues Palette 2 的亮／暗主題；`.rpg-theme` 只將像素場景顏色對應到專案色票，不覆寫介面 tokens。首頁只增加一個入口。

內容由 `data/rpg/families.json`、獨立審核紀錄與原題庫產生，server function 載入小型副本，不需要 D1 才能遊玩，也不把整份題庫放進首頁 bundle。詳細來源核對見 [RPG-CONTENT-AUDIT.md](RPG-CONTENT-AUDIT.md)。

9 組雙語題目家族共 18 筆語言紀錄，並非 18 道不同題。目前正式委託都是單選題；四種題型的純判題規則有 fixture 測試；本次發布只驗收單選內容，不納入尚未提交的共用配對元件變更。

同一題家族兩個語言的 hash 合成版本：語言切換不重複加分、任一內容版本更新會撤除舊版掌握證據。已保存的舊戰鬥若遇內容更新，要求重新接任務，不偷偷替換已答題。匯入失敗保留原存檔；寫入失敗明示未保存，仍可匯出記憶體中的進度。

## 驗證

- `pnpm verify`：原品質門檻，加上 RPG 內容一致性與進度規則兩個檢查。
- `node scripts/build-rpg-content.mjs --check`：18 筆題目的版本、審核、雙語配對與生成資料一致。
- `node scripts/verify-rpg.mjs`：獎勵去重、80% 通關、1／3／7／14／30 天排程、提示不算獨立掌握、未補正錯題、雙語家族、四種判題、恢復、內容變更與無效匯入。
- 本地 Chrome 自動操作與桌面／手機截圖放在 `.research/rpg-mode/`，不納入版本庫。瀏覽器驗證細項以 `browser-results.json` 與 `browser-edge-results.json` 為準。
- 全專案額外 `tsc --noEmit` 仍有既有錯誤。已由暫存的 Git index 基線重現原錯誤；本次 RPG 檔案無新增型別錯誤。原模擬考結果路由、部分既有資料型別與 Cloudflare 型別缺漏不在本次修改範圍。

## 明確界線

- 此版是三個短任務的完整循環，並非整個 D1 領域或完整 AIF-C01 準備內容。
- 其餘四區、Boss、公會試煉、更多證照與雲端存檔尚未實作。
- 任務手冊目前提供領域與文字搜尋；尚無獨立難度／時長選單。
- 知識筆記在作答後顯示，尚未另建收藏冊與外觀裝備系統。
- 無即時 AI 產題、程式執行環境、產業／職務支線或通過率預測。
- 本地存檔不等於完整離線模式；內容請求失敗仍可到營地備份，但不能開始新任務。
- 本次提交與部署採獨立 checkout 驗證；原工作區其他 staged 改動保持原狀。部署結果以 Git commit 與 Cloudflare 版本紀錄為準。
