# University AI Courses — Reference

Popular open courseware and university courses to structure learning paths around.

## Foundational ML

| Course | Institution | Format | Key Topics |
|--------|-------------|--------|------------|
| CS229 Machine Learning | Stanford | Lectures + problem sets | Linear models, SVMs, neural nets, unsupervised learning, RL intro |
| Machine Learning Specialization | Coursera (Andrew Ng) | Video + quizzes + labs | Regression, classification, neural nets, decision trees, clustering |
| AI for Everyone | Coursera (Andrew Ng) | Video + quizzes | Non-technical AI literacy, business strategy |
| 6.S191 Intro to Deep Learning | MIT | Lectures + labs | DL basics, CNNs, RNNs, generative models, RL |

## Computer Vision

| Course | Institution | Format | Key Topics |
|--------|-------------|--------|------------|
| CS231n | Stanford | Lectures + assignments | Image classification, CNNs, object detection, segmentation, GANs |
| EECS 498/598 DL for CV | U Michigan (Justin Johnson) | Lectures + assignments | Similar to CS231n, newer |

## NLP & LLMs

| Course | Institution | Format | Key Topics |
|--------|-------------|--------|------------|
| CS224n NLP with Deep Learning | Stanford | Lectures + assignments | Word vectors, transformers, pretraining, LLMs, RLHF |
| CS324 LLMs | Stanford | Readings + projects | LLM training, evaluation, deployment, safety |
| COS 597G Understanding LLMs | Princeton | Seminars | LLM internals, emergent abilities, reasoning |
